# CVEVault

Security-focused vulnerability intelligence platform for CVE ingestion, monitoring and analysis.

---

## Features

- CVE ingestion from external APIs
- Vulnerability monitoring dashboard
- Severity filtering
- Search by CVE and affected systems
- Automatic updates
- REST API architecture
- JSON vulnerability processing
- Pagination support

---

## Tech Stack

### Backend
- PHP
- MySQL
- REST APIs

### Frontend
- HTML
- Bootstrap
- JavaScript
- jQuery

### Security
- CVE feeds
- Threat intelligence
- Vulnerability analysis

## Architecture

```txt

```
